## 本次 Fandom 补查

婴儿图片是出生场景的背面视角，只裁取头部及附近区域；详情中明确标注“出生场景（背面）”，不把父亲的面孔当作婴儿头像。

葡萄牙语和西班牙语专题 Wiki 的页面目录及 Fandom 定向检索中，仍未找到可核实的加夫列尔剧照。未使用作者或其他同名人物的照片替代。

## 素材处理

原始链接、署名、角色核对依据、裁切坐标在 `sources.json` 中。最终图片为 384 × 480 JPEG；皮埃特罗与赫里内勒多的暗光图片做了轻微伽马提亮。原图缓存位于 `.cache/portraits-originals/`，Fandom 原始 WebP 另保存在 `.cache/portrait-fandom/`，通过浏览器按原尺寸转为 JPEG 后裁切。

在项目根目录运行 `powershell -NoProfile -File scripts/prepare-portraits.ps1` 可从缓存重建头像；使用 `-Id gaston` 可只处理某张图。运行 `python scripts/build-standalone.py` 重建独立 HTML。图片版权归各自权利人，详情保留来源链接。
