# 百年孤独 · 布恩迪亚家族图谱

**Buendía Family Tree** — an interactive family tree and novel timeline for *One Hundred Years of Solitude*, with a Chinese interface.

通过人物关系图与事件时间线，探索加西亚·马尔克斯《百年孤独》中布恩迪亚家族的七代传承。

**[打开在线图谱 →](https://drzhiwang.github.io/buendia-family-tree/)**

> **含全书剧透。** 建议在桌面浏览器中使用，窗口宽度至少 1280px；当前布局未针对手机优化。

## 可以探索什么

- **七代家族关系**：29 个人物条目，包含主要家族成员、关键关联人物，以及十七个奥雷里亚诺的合并条目。
- **人物介绍**：身份、生平、关系变化与结局；同名人物以世代和身份区分，并提供西文名对照。
- **66 个事件**：分为迁徙与建镇、家族扩展、内战、繁盛与转折、屠杀与衰败、最后一代六个阶段。
- **人物与事件联动**：从人物查找相关事件，也可以从事件中的头像继续探索人物。
- **搜索与关系筛选**：支持中文名、别名和西文名，可筛选亲子、婚姻与伴侣连线。

人物关系与事件依据**小说**整理。头像采用的剧集形象仅供辨认参考，时间线不按电视剧集顺序排列。

## 如何使用

1. 搜索姓名，或点击图谱中的人物，查看简介与亲属关系。
2. 点击人物详情中的事件，跳转到时间线；通过“人物详情”标签可切回刚才的人物并保留阅读位置。
3. 点击时间线中的事件，展开描述并在图谱中定位相关人物。再次点击同一时间线条目可收起。
4. 拖动画布平移，使用鼠标滚轮缩放；左侧 **01–07** 可定位各代人物。
5. 点击“全图”查看完整家族树，点击“阅读比例”恢复 80% 的阅读视图。
6. “全部事件”清除人物事件筛选；“↺”重置选择、筛选和视图。

切换侧栏标签不会改变当前图谱高亮。事件选择展示的是相关人物，图谱仍保留全书关系，并不模拟某一时刻已经形成的家族结构。

| 快捷键 | 操作 |
| --- | --- |
| `/` | 搜索人物 |
| `Tab` | 在可操作元素之间移动 |
| `Enter` / 空格 | 激活当前按钮或人物 |
| 方向键 | 画布获得焦点时平移；标签栏获得焦点时左右切换标签 |
| `+` / `-` | 画布获得焦点时缩放 |
| `Esc` | 取消当前选择或关闭对话框 |

## 本地运行

下载仓库（**Code → Download ZIP**）并解压，然后用现代浏览器打开 `index.html`。无需安装依赖、运行构建命令或配置后端。

也可以在项目目录启动一个本地静态服务器：

```sh
python -m http.server 8000
```

随后访问 <http://localhost:8000>。

应用脚本、数据与头像随文件提供。Noto Sans SC 和 Noto Serif SC 字体通过 Google Fonts 加载；无法联网时会使用系统备用字体。

## 项目结构

```text
index.html          页面入口
styles.css          页面样式
app.js              搜索、导航、人物详情与时间线交互
data.js             人物、关系及头像信息
events.js           事件内容、人物引用与章节信息
graph-layout.js     家族关系图布局与连线
favicon.svg         网站图标
assets/
  portraits/        人物头像、剪影与来源记录
```

人物和事件通过稳定 ID 关联，避免重复姓名造成混淆。编辑人物介绍请修改 `data.js`，编辑事件请修改 `events.js`；正文使用空行分段。

## 部署到 GitHub Pages

本项目使用多文件静态站点，无需生成独立 HTML。

1. 将 `index.html`、样式、脚本、图标以及整个 `assets/` 文件夹放在仓库根目录，保持原有文件名与文件夹结构。
2. 打开仓库的 **Settings → Pages**。
3. 选择 **Deploy from a branch → main → /(root)**，点击 **Save**。
4. 部署完成后，在同一页面点击 **Visit site**。构建进度可在 **Actions** 中查看。

此仓库的站点地址为 <https://drzhiwang.github.io/buendia-family-tree/>。更新发布分支中的网站文件后，GitHub Pages 会重新部署。

## 阅读与资料说明

人物简介和事件描述为原创概述与解读，不能替代原著。不同译本的姓名可能不同，页面保留西文名，并兼容部分常见中文译名。

- 蕾贝卡按收养关系列入第二代，不作为创始夫妇的亲生女儿。
- 奥雷里亚诺·何塞不包含在“十七个奥雷里亚诺”之中。
- 双胞胎的身份交换属于小说中的疑问，不据此改写确定的亲子关系。
- 事件序号不代表公历年份。长期过程按主要转折排列；涉及回叙或多个阶段时，以描述中的先后关系为准。
