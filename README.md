# 百年孤独 · 布恩迪亚家族图谱

面向 1080p 桌面浏览器的中文交互人物关系图与 66 个小说事件时间线。完整七代、关键关联人物、全书剧透。原生 HTML / CSS / JavaScript / SVG，无需前端框架或后台服务；使用 Google Fonts 在线加载 Noto Sans SC 与 Noto Serif SC。

## 打开

直接用现代 Chrome、Edge、Firefox 或 Safari 打开 `index.html`。双击文件即可使用。Noto 字体通过 Google Fonts 在线加载，失败时回退到微软雅黑等系统字体；图片与应用数据仍保存在本地。

也可在本目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。此命令只是可选的本地预览。

## 操作

- 使用鼠标拖动画布，滚轮缩放。默认以 80% 阅读比例显示创始夫妇及邻近人物。
- 通过左侧 01–07 以 80% 比例定位各代的主要人物；点击“全图”查看七代总览，点击“阅读比例”恢复 80%。
- 搜索中文名、别名、西文名，支持忽略西文重音和部分常见中文译名差异。重名结果列出世代及身份。
- 点击人物打开关系详情；点击详情中的姓名继续探索。十七子条目会展开名单与说明。
- 亲子、婚姻、伴侣筛选控制画布连线；“亲子”同时控制亲生和收养关系，统一使用实线；详情始终列出完整关系。其他联系在选中相应人物，或事件同时涉及两端人物时绘制。
- 键盘：`/` 搜索，搜索中上下键选择结果，Enter 确认；Tab 可选择人物和按钮，Enter 或空格打开人物；画布内方向键平移，`+` / `-` 缩放；Esc 取消当前选择或关闭对话框；未选中人物或事件时，可收起侧栏。
- “收起侧栏／展开侧栏”控制右侧面板；“↺”清除选择、搜索与筛选，恢复默认阅读视图并展开侧栏。

## 时间线

右侧默认显示分为六个阶段的 66 个小说事件。序号只表示先后顺序，不是公历年份；持续性事件按主要转折排列。条目默认折叠，点击展开摘要和人物头像，再次点击收起。

- 点击事件：相关人物及其间启用的关系高亮，画布自动适配这些人物。完整家族树保留，不模拟该时刻已登场人物或已形成关系。
- 点击人物：打开人物详情，列出相关事件，并将“时间线”标签筛选为该人物的事件。
- 在人物详情里点击事件：返回时间线并滚动至该事件，保留该人物的事件筛选；事件里的头像可返回人物详情。
- 从人物详情打开事件后，“人物详情”标签仍可切回最近查看的人物，并保留正文阅读位置；切换标签不会改变当前图谱高亮。再次从人物详情打开同一事件会保持展开，只有在时间线中重复点击该事件才会收起。选择另一人物会更新详情，全图、取消选择或重置会清除保留的详情。
- “全部事件”或筛选标签的 × 仅清除事件筛选；“全图”取消当前高亮并显示完整家族树；“↺”清除所有选择、搜索、关系筛选和事件筛选。
- 事件总览可能临时缩小文字。“阅读比例”会恢复 80% 并定位事件的首位关联人物，保留全部事件高亮；没有选择时恢复比例并保留当前画布中心。

事件数据独立维护在 `events.js`：`id`、`order`、`phase`、`title`、`summary`、`personIds`，另有供编辑核对的 `chapters`。人物引用沿用 `data.js` 的稳定 ID，不使用重复姓名作为键。66 个事件均补充起因、经过与后续影响，以两个段落呈现；`summary` 中用空行分段。

时间线补入梅尔基亚德斯去世、赫里内勒多获撤销死刑、乌尔苏拉失明、圣索菲亚离家、阿马多尔遇害和庇拉尔去世六个独立节点。圣索菲亚离家与费尔南达去世分别关联各自涉及的人物；阿马多尔遇害排在“罗马归来的何塞遇害”之前，后者以何塞的死亡为主要时间节点，其返乡背景早于阿马多尔到访。乌尔苏拉失明为持续过程，按晚年记忆与家务能力的集中呈现排列。

## 数据与边界

`data.js` 独立维护人物及关系，使用稳定 ID 区分同名者。`generation` 为家族代际，关联人物取 `null`；`row` 和坐标仅服务布局，不表示关联人物的出生年代。`families` 记录有方向的亲生或收养关系，`links` 记录婚姻、伴侣与辅助关系。简介均为原创概述。

29 个人物条目（含十七子合并条目）均扩写为三段，涵盖身份与早期经历、关系与性格变化、结局及阅读理解；十七子的成员说明也补充了各自作用与命运。`description` 使用空行分段，页面以经过 HTML 转义的独立段落显示，不截断正文。人物事实与文学解读分开表达；没有足够经历可供描述的人物，不虚构性格或心理。

本轮扩写结合目录中的《百年孤独》文本与既有人物、事件核对记录，以原创中文概述呈现，不拼接原著段落。保留死因、双胞胎身份等未解之处，明确区分人物见证、推测与确认情节；涉及性、暴力及死亡时仅保留理解剧情所需的非露骨描述。附带文本存在译名及部分数字差异，统一沿用图谱既有命名和下列谱系约定。

- 蕾贝卡按照收养关系置于第二代，与其他亲子关系使用相同实线，保留“养女”身份说明。
- 庇拉尔是阿尔卡蒂奥和奥雷里亚诺·何塞的母亲，两人的父亲分别为何塞·阿尔卡蒂奥和上校。
- 奥雷里亚诺·何塞不包含在上校的十七个儿子中；十七子由十七位不同母亲所生。合并条目列出五名具名人物，其余十二人合并，不补造姓名。
- 阿尔卡蒂奥与圣索菲亚标记为伴侣，不将共同生育自动认定为婚姻。详情中的兄弟姐妹依据共同亲生父母推导，包含同父／同母关系。
- 双胞胎沿用小说中姓名和常见谱系；不将交换身份的猜测当作已确认事实。
- 阿玛兰妲·乌尔苏拉同时是奥雷里亚诺·巴比伦的姨母和恋人。最后一个孩子的两条亲生关系分别连向这两人。
- 涉及订婚、未成的求爱或复杂情感纠葛时使用辅助关系说明，不当作正式婚姻。仅收录关键人物，不涵盖全部次要角色、未出生的孩子或所有祖先。

## 参考资料

以加西亚·马尔克斯《百年孤独》（Cien años de soledad，1967）为作品对象，交叉核对以下网页的人物章节（2026-11-18）：

- https://es.wikipedia.org/wiki/Cien_a%C3%B1os_de_soledad
- https://en.wikipedia.org/wiki/One_Hundred_Years_of_Solitude
- https://www.sparknotes.com/lit/solitude/ （分章事件核对，具体链接见 `events.js`）

不同译本存在姓名差异，网页同时提供西文名。参考网页也可能出现错误或彼此不一致，未直接复制其文本；例如上校的妻子按小说情节记录为 Remedios Moscote。

## 验证

运行 `node tests/data.test.js` 校验唯一 ID、关系引用、七代传承、分组计数、关键亲子关系及人物卡片位置。运行 `node tests/portraits.test.js` 校验头像文件、来源元数据、裁切范围及同名人物的头像区分。运行 `node tests/events.test.js` 校验时间线引用、分组、事件顺序及关键人物对应。`tests/timeline.browser.js` 是接收 Playwright page 的浏览器检查函数，可通过浏览器工具的 `browser_run_code_unsafe` 的 `filename` 参数执行；覆盖双向联动、筛选保持、多人物适配、空事件列表、桌面、键盘、面板收起与重置。`tests/desktop.browser.js` 验证 1920×1080、1920×950 和 1536×760 视口的实际字号、440px 侧栏、阅读比例、来源展开和鼠标操作。另行验证头像失败回退及断网打开。

## 人物头像

已为 27 位人物配上 Netflix 剧集剧照，加夫列尔仍采用中性剪影，十七子合并条目使用带“17”的群像剪影。卡片、搜索结果和详情使用同一人物 ID 对应的图片。剧照时期和可核实的演员姓名在详情中显示；两位后代当前采用童年剧照，在人物详情中明确标注。

图片保存在 `assets/portraits/`，全部可离线加载。发生图片加载错误时，卡片与详情自动改为剪影。完整名单及出处见 [人物头像与来源](assets/portraits/README.md)。

## 桌面阅读设置

页面以 1920×1080 屏幕为目标，也按浏览器工具栏占用后的 1920×950 视口及 1536×760 桌面缩放场景验证。不提供手机断点或底部抽屉。

正文与主要操作为 16px，辅助信息至少 14px，人物详情标题为 28px。图谱默认比例下姓名约 19.2px，身份和代际说明约 14.4px。顶部为 64px 页头和 72px 工具栏，左右留白 24px；440px 侧栏可收起。人物图片时期保持可见，摄影和来源信息可按需展开。

## 图谱布局

人物按七代排列，同层采用统一间距，相关伴侣就近放置。默认使用固定 80% 阅读比例，不为了容纳全部列而缩小文字。世代导航使用各代的 `focusPersonId` 定位；单个人物选择至少使用 100% 比例。只有全图总览、事件自动适配和用户主动缩小时允许更小比例。

`graph-layout.js` 将关系数据转换为绘图路径，保留完整的逻辑关系，并将重复的家族线段合并。每段线保留其对应的关系集合，所以人物选择、事件高亮和类型筛选仍依据实际关系工作。

庇拉尔的两个子女分支使用分开的连接点；各亲子支线独立布置；跨代伴侣关系沿卡片之间的通道布线。圆点只标记同一家族的真实支线汇合，交叉处以背景色间隙区分，选中的线路始终画在前面。

运行 `node tests/layout.test.js` 检查全部 53 条关系的绘图覆盖、卡片碰撞、重合线段、路径边界和汇合点。`tests/layout.browser.js` 验证初始视野、世代定位、亲子关系区分、筛选与实际 SVG 曲线；可用与时间线浏览器检查相同的方式运行。独立 HTML 的构建脚本同时内嵌布局模块。

额外亲属连线（表亲、姨甥、姑侄）在相关人物或事件被选中时显示文字标签，并在人物详情中单列为“亲属联系”，与友情等其他联系区分。配色保持不变。

## 在线字体

图谱人物姓名、人物详情标题、正文、辅助信息与控件使用 Noto Sans SC 的 400 和 500 字重；仅书名“百年孤独”使用 Noto Serif SC 的 500 字重。两套字体通过 Google Fonts 加载，并采用 `display=swap`。字体下载期间显示系统备用字体。英文姓名和序号优先使用 Segoe UI。独立 HTML 内嵌应用样式、脚本、数据和头像，同时保留 Google Fonts 样式表链接；字体不会打包进 HTML。
